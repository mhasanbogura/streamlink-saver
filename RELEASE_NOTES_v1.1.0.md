## What’s new

- Added a compact success notification when a right-clicked link is handed to the GitHub Pages `.strm` download route.
- Added compact 16 px, 32 px, 48 px, and 64 px blue link icons.
- Keeps the hosted handoff at https://mhasanbogura.github.io/streamlink-saver/.

## Install

Download `streamlink-saver-v1.1.0.zip`, extract it, then open `chrome://extensions`, enable Developer mode, and select **Load unpacked** for the extracted `extension` folder.
