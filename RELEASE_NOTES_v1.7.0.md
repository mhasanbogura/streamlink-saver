## What’s new

- Added a dedicated **Save path** settings page, opened from the gear icon in the extension popup.
- The default path is `Downloads/`, which writes `.strm` files at the Chrome Downloads root.
- Set a custom path such as `Downloads/Direct Link` without editing code; the selection is saved for future popup and right-click downloads.

## Configure the location

Open the StreamLink Saver popup, select the gear icon, enter your path, and choose **Save path**. Use `Downloads/` for the root or `Downloads/Direct Link` for a subfolder.

## Install

Download `streamlink-saver-v1.7.0.zip`, extract it, then open `chrome://extensions`, enable Developer mode, and select **Load unpacked** for the extracted `extension` folder.
